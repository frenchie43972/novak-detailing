# Novak Detailing Co.

Single-page marketing website for Novak Detailing Co., serving the Akron–Canton area.

## Stack

- Nuxt 4
- Vue 3 and TypeScript
- Vanilla CSS
- Static generation
- Nuxt Image, Sitemap, Robots, and ESLint

## Development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run lint
npm run generate
```

The site is intentionally scaffolded with placeholder content. Final design, copy, images, social links, SEO metadata, and hosting configuration will be added only after approval.
